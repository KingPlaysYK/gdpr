# Prompt For A New Codex Session

Use this prompt when starting a fresh Codex session:

```text
Continue the Shamela language-books lexicon project.

Always keep the active work anchored to a GitHub issue. The umbrella goal issue is:
- https://github.com/KingPlaysYK/gdpr/issues/2

The sourced lexicon tracker is:
- https://github.com/KingPlaysYK/gdpr/issues/85

First read:
- codex/CONTEXT_PACK.md
- codex/NEXT_ACTION.md
- codex/PROJECT_MEMORY.md
- codex/SESSION_LOG.md
- docs/lexicon-workflow.md
- docs/lexicon-entry-schema.md
- docs/source-reference-schema.md

Then complete only the next small chunk covered by a GitHub issue, save progress, update NEXT_ACTION.md and SESSION_LOG.md, and commit/push any GitHub-tracked updates.

Active policy: contextual translation only. Do not add literal translation layers or word-by-word gloss layers. If an Arabic word, phrase, title term, or letter is being discussed as Arabic, keep it Arabic and apply tashkeel when the form itself matters.
```
