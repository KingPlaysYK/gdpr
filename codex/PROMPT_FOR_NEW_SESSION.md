# Prompt For A New Codex Session

Use this prompt when starting a fresh Codex session:

```text
Continue the Shamela translation project.

First read:
- codex/CONTEXT_PACK.md
- codex/NEXT_ACTION.md
- codex/PROJECT_MEMORY.md
- codex/SESSION_LOG.md

Then complete only the next small chunk, save progress, update NEXT_ACTION.md and SESSION_LOG.md, and commit/push any GitHub-tracked updates.
```
